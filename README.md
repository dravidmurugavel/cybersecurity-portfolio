## How this works
Each topic is taught hands-on, tied to a real-world incident (CVE/breach/malware), then documented
as a write-up. Projects are real tools/scripts built while working through a domain — not tutorials
copied, actual work done.

## Structure
```
writeups/<phase>/<domain>/   → concept write-ups, one markdown file per subtopic
projects/<phase>/<domain>/   → real code/tools built for that domain
resources/                    → cheatsheets, reference notes
index.html                    → interactive roadmap tracker (progress saved in browser)
```
