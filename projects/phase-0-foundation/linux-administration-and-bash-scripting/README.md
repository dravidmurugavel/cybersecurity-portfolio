# Linux Administration & Bash Scripting — Projects

_Phase 0 — Applied Projects_

Hands-on tools built while working through the [Linux Administration & Bash Scripting write-ups](../../../writeups/phase-0-foundation/linux-administration-and-bash-scripting/README.md), including the Module 10 (Security & Hardening) capstone. Each project below turns investigative command-line knowledge into a working, reusable tool.

## Projects

| Project | Type | Summary |
|---|---|---|
| [LinSec Auditor](LinSec%20Auditor/README.md) | Bash (modular) | Read-only Linux security auditing tool. Runs 13 security checks (privileged accounts, SUID/SGID, sudo config, listening ports, firewall, SSH exposure, cron, systemd, failed authentication, and more), scores and prioritizes findings through a dedicated risk engine, and reports via terminal or JSON. Built following a documented SDLC (requirements → design → implementation → testing → security assessment → release). |
